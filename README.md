# WonderVexa Video Automation

A zero-budget-first project for creating original 9:16 magical transformation and visual-story Shorts.

## Current status

The main branch contains morning and evening **draft-package** workflows (scheduled for 06:15 and 18:15 Nepal time). It creates scripts, four scene-by-scene visual prompts with continuity and negative-prompt guidance, title/description, long-tail keywords, hashtags and a subject-themed SVG thumbnail draft. The offline content factory is template-based; it does not generate AI footage or publish.

The RSS/Atom research adapter is implemented and wired into the scheduled workflow, but is disabled until public feed sources are reviewed and approved. RSS items are research signals, not verified social-platform trends.

A fail-closed YouTube Data API uploader scaffold is now present. It defaults to dry-run, requires separate runtime gates and OAuth token JSON, and is not connected to the scheduled workflow. No upload has been attempted.

## Safety and budget rules

- Target budget: NPR 0. Use only sources with documented no-cost terms.
- Target cadence: two draft packages per day, one morning and one evening. These are draft packages, not two finished AI-generated videos.
- Never silently enable paid billing, paid fallback, auto-recharge, or a payment method.
- Never commit API secrets or credentials.
- Video generation stays disabled until a provider passes the evidence gate and the user explicitly approves a specific test.
- Unattended daily publishing is the requested end state where official platform rules permit; publishing remains disabled until OAuth, app review/audit, account eligibility and zero-cost gates pass.
- Keep the separate Nepal News automation project out of scope.
- Viral performance cannot be guaranteed.

## Daily drafts

GitHub Actions schedules draft-package creation at 06:15 and 18:15 Nepal time. Separate watchdogs check the morning and evening schedules at 11:30 and 23:30 Nepal time. Draft packages and rendered procedural previews are saved as workflow artifacts for 14 days. Schedules are best-effort and may be delayed or skipped. Scheduled Actions are best-effort and may be delayed or skipped.

The current curated idea bank contains 50 evergreen seeds. Used topics are avoided while unused ideas remain; after exhaustion, the least-recently-used idea is recycled. Cross-run history uses GitHub Actions cache and is best-effort, not a permanent ledger. These topics are not live trends and are not generated by an AI text model.

## Trend research adapter

See [Trend research adapter](docs/TREND_RESEARCH.md). It supports reviewed public HTTPS RSS/Atom feeds, freshness filtering, source attribution and research-only story briefs. No feeds are currently approved or enabled; no external feed requests occur by default.

## Media assembly and quality checks

The current scheduled renderer creates a short procedural motion-graphics preview with offline synthetic English narration; it is not realistic AI-generated footage, does not use the recurring magician character, and is not the Hindi-voice magic-reel target. Local FFmpeg utilities can also assemble already-generated, licensed clips, add a WonderVexa watermark, export a thumbnail and check final MP4/PNG technical properties. They do not create source footage or assess visual quality. See [Daily content pipeline](docs/DAILY_CONTENT_PIPELINE.md).
