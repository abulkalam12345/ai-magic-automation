# AI Magic Video Automation

A zero-budget-first project for producing original 9:16 magic and visual-knowledge Shorts with a consistent fictional adult character.

## Current status
This repository is in the **planning and feasibility** stage. No video-generation provider has been validated yet, and no video has been generated or uploaded.

## Project rules
- Free services only; never silently enable paid billing.
- Do not assume GitHub-hosted runners provide a GPU.
- Prove a short sample before building a large automation pipeline.
- Require explicit user approval before every YouTube upload.
- Keep the separate Nepal News automation project completely out of scope.
- Never commit passwords, API keys, OAuth tokens, or other secrets.

## Planned first proof
An 8–12 second vertical video in which a fictional adult woman uses magic to restore a wilted flower. The proof must record actual cost, provider quota, queue and render time, and pass human visual-quality review before further implementation.

## Important
A free model is not the same as free compute. Provider availability, quotas, licenses, and terms must be checked before use. If no genuinely free suitable video route is available, the project must report that blocker rather than incur charges.
